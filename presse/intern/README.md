Interne Presseartikel (vollständige, eigenständige HTML-Dateien je Spieltag).

HTML-Datei hier per GitHub-Weboberfläche hochladen ("Add file" → "Upload
files"), danach im Admin-Bereich der App unter "Presse verwalten" → "Intern"
einen neuen Eintrag anlegen, den Dateipfad (z.B.
`presse/intern/dateiname.html`) eintragen und optional das zugehörige Spiel
zuordnen (erzeugt den Link im Spielplan).
